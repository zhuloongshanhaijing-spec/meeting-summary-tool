# Contributing

Thanks for helping improve the project. Before opening an issue or pull
request, remove all real meeting material, credentials, absolute local paths,
and generated private outputs.

- Run `python3 -m unittest discover tests` for behavior changes.
- Describe the macOS/Linux environment and whether local models were used.
- Keep the evidence-link and privacy guarantees intact.
- Do not add model weights, FFmpeg binaries, or other third-party artifacts
  without a documented license review.

By submitting a contribution, you confirm that you have the right to submit
it under the repository's PolyForm Noncommercial License 1.0.0.
