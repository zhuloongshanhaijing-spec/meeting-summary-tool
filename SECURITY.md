# Security policy

Please do not post suspected vulnerabilities, privacy issues, or leaked
credentials in a public issue. Use GitHub's private vulnerability reporting
feature for this repository when it is available. If it is unavailable, open a
minimal public issue asking the maintainer to enable a private reporting path;
do not include exploit details or sensitive data.

This tool is designed for local processing. Never attach real meeting audio,
transcripts, notes, credentials, or generated private outputs to a public
report.
